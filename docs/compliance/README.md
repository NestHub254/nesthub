## Option A (summary)

- Property owners / property-management businesses determine purposes and essential means for tenant and property information they control in their workspaces (where the arrangement so provides).  
- SIONA processes that information as a **processor** under documented instructions.  
- SIONA is an **independent controller** for its own corporate, administrative and infrastructure processing where it determines purposes and means.  
- NestHub remains the partner’s product; SIONA does not own NestHub IP or customer relationships.  
- Dual ODPC registration does **not** make SIONA controller of all NestHub personal data.  
- No joint-controller claim without a written agreement.  
- No public DPO name until appointment is signed and publication authorised.
